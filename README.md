# 🏃‍♂️ Interval Timer

A beautiful and responsive Flutter interval timer app perfect for workouts, HIIT training, and productivity sessions.

## ✨ Features

- **Customizable Intervals**: Set work time, rest time, and number of rounds
- **Preset Workouts**: Quick access to Tabata, HIIT, and other popular workout formats
- **Audio Alerts**: Sound notifications for interval changes
- **Responsive Design**: Works perfectly on mobile, tablet, and desktop
- **Progressive Web App**: Install on iOS/Android home screen
- **Offline Support**: Works without internet connection

## 🚀 Live Demo

Try the web version: [Interval Timer Web App](https://your-domain.com)

## 📱 Installation

### iOS (iPhone/iPad)
1. Open Safari and go to the web app URL
2. Tap the Share button (📤)
3. Select "Add to Home Screen"
4. Name it "Interval Timer" and tap "Add"

### Android
1. Open Chrome and go to the web app URL  
2. Tap the menu (⋮) and select "Add to Home screen"
3. Name it "Interval Timer" and tap "Add"

### Desktop
Visit the web app URL in any modern browser.

## 🛠️ Development

Built with:
- **Flutter 3.32.5** - Cross-platform framework
- **Riverpod** - State management
- **SharedPreferences** - Local data storage
- **AudioPlayers** - Sound effects

### Run Locally

```bash
# Clone the repository
git clone https://github.com/yourusername/Interval-Timer.git

# Install dependencies
flutter pub get

# Run the app
flutter run
```

### Build for Web

```bash
# Build web version
flutter build web

# Serve locally
flutter run -d web-server --web-port 8080
```

## 🎯 Preset Workouts

### Tabata (4 minutes)
- Work: 20 seconds
- Rest: 10 seconds  
- Rounds: 8

### HIIT (7 minutes 40 seconds)
- Work: 30 seconds
- Rest: 15 seconds
- Rounds: 10

### Quick Workout (5 minutes)
- Work: 45 seconds
- Rest: 15 seconds
- Rounds: 5
